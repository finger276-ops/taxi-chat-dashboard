# Дайджест водительских чатов — патч v3.4

Версия 3.4 обновляет вкладку **«Вся лента»** и добавляет быстрые действия модерации прямо из выбранного сообщения.

## Что изменилось во вкладке «Вся лента»

По умолчанию таблица теперь показывает колонки в таком порядке:

```text
Дата
Текст
Тема
Теги
Чат
Автор
Тональность
Ссылка
```

Технические поля вроде `message_id`, `event_id`, `discussion_id` пользователю не показываются.

## Новая функциональность

После выбора сообщения в ленте администратор может:

- назначить или изменить **тему сообщения**;
- назначить сообщению другой **инфоповод**;
- найти нужный инфоповод через поиск;
- создать новый инфоповод и сразу назначить туда сообщение;
- пометить сообщение как нерелевантное для текущего инфоповода;
- скрыть сообщение во всем дашборде;
- закрепить сообщение как ключевое.

## Как сохраняются правки

Назначение темы сохраняется как ручная правка сообщения. Если используется Supabase, правка сохраняется в таблице `dashboard_manual_rows` с типом `message_topic_overrides`.

Назначение инфоповода использует существующую механику переноса сообщения и сохраняется в `message_overrides`.

## Что заменить

Минимально заменить в GitHub:

```text
src/app.py
src/manual_db.py
README.md
```

После замены сделать:

```text
Commit → Push origin
```

При необходимости в Streamlit Cloud:

```text
Manage app → Reboot app
```
