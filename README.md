# Дайджест водительских чатов

Версия 3.5: добавлена выгрузка дайджеста в Word и PDF.

## Что добавлено

В разделе «Инфоповоды» появился блок **«Выгрузка дайджеста»**.

Доступна выгрузка за выбранный период или несколько периодов:

- Word (`.docx`);
- PDF (`.pdf`).

Структура выгрузки:

1. Заголовок: `Дайджест водительских чатов | период`.
2. Количество релевантных сообщений.
3. Тональность: нейтрал / негатив / позитив.
4. Блок **«Главное за неделю»**.
5. Блок **«Обсуждения недели»** по темам в порядке убывания количества сообщений.
6. Для каждой темы:
   - доля сообщений;
   - тональность темы;
   - тезисное описание;
   - ключевые цитаты.

В интерфейсе можно выбрать:

- количество тем в выгрузке;
- количество цитат на тему.
