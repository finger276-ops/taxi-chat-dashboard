# Дайджест водительских чатов — патч v3.3

Версия 3.3 добавляет поддержку файлов с готовой разметкой тем.

## Что добавлено

Если в загружаемой выгрузке есть колонки:

- `Основная тема`
- `Все темы`
- `Все темы (список)`
- `Релевантное`

дашборд автоматически распознает их и сохраняет в нормализованных данных.

## Как используется разметка

`Основная тема` не заменяет инфоповоды полностью. Она используется как верхний тематический слой:

```text
Основная тема из файла
↓
внутри нее алгоритм группирует обсуждения
↓
формируются конкретные инфоповоды
```

Это снижает риск, что в один инфоповод попадут сообщения из разных крупных тем, например `Коэффициент` и `Законы и налоги`.

## Что изменилось в интерфейсе

В фильтрах появился пункт:

```text
Тема из файла
```

Он отображается только для периодов, где в исходной выгрузке есть колонка `Основная тема`.

В таблице инфоповодов и карточке инфоповода также появляется поле `Тема из файла`, если такие данные есть.

## Релевантность

Если в колонке `Релевантное` стоит `False`, `Нет`, `0` или похожее значение, сообщение не участвует в построении инфоповодов и саммари, но остается в сохраненной базе сообщений.

## Что заменить

Минимально заменить в GitHub:

```text
src/app.py
src/preprocess.py
src/import_adapters.py
README.md
```

После замены сделать:

```text
Commit → Push origin
```

При необходимости в Streamlit Cloud:

```text
Manage app → Reboot app
```
