# Дайджест водительских чатов

Версия 3.6: добавлено массовое объединение нескольких инфоповодов.

## Что изменено

В карточке инфоповода во вкладке **«Правки»** обновлен блок объединения:

- можно выбрать целевой инфоповод;
- можно выбрать сразу несколько дополнительных инфоповодов для объединения;
- если целевой инфоповод — текущий, выбранные темы будут присоединены к нему;
- если целевой инфоповод другой, текущая тема и выбранные дополнительные темы будут присоединены к целевому;
- объединение учитывает скрытые внутренние события/волны, которые находятся под видимой темой.

## Как использовать

1. Откройте карточку инфоповода.
2. Перейдите во вкладку **«Правки»**.
3. В блоке **«Массовое объединение инфоповодов»** выберите целевой инфоповод.
4. В поле **«Дополнительные инфоповоды для объединения»** выберите одну или несколько тем.
5. Нажмите **«Объединить выбранные»**.
