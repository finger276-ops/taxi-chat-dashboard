# Дайджест водительских чатов — v2.6

Версия 2.6 добавляет редактируемое саммари периода перед таблицей инфоповодов.

## Что нового

- Перед блоком «Инфоповоды» появился блок **«Саммари периода»**.
- Саммари автоматически собирает основную информацию по выбранному периоду или нескольким периодам:
  - общее количество сообщений;
  - количество чатов и авторов;
  - долю негатива;
  - наиболее активные чаты;
  - основные инфоповоды;
  - самые частые темы/теги;
  - основные источники негатива.
- В режиме администратора саммари можно вручную отредактировать.
- Ручное саммари сохраняется в Supabase в `dashboard_manual_rows` и не пропадает после перезапуска приложения.
- Если ручное саммари очистить, дашборд снова покажет автоматическую версию.

## Что заменить в GitHub

Замените файлы:

```text
src/app.py
src/manual_db.py
README.md
```

После замены выполните:

```text
Commit → Push origin
```

Если Streamlit Cloud не обновился автоматически:

```text
Manage app → Reboot app
```

## Проверка

Вверху дашборда должна появиться подпись:

```text
Версия 2.6: добавлено редактируемое саммари периода перед инфоповодами
```

В разделе «Инфоповоды» перед метриками и таблицей должен появиться блок:

```text
Саммари периода
```

В режиме администратора внутри него доступен раскрывающийся блок **«Редактировать саммари»**.
