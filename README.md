# Дайджест водительских чатов — v3.0

Версия 3.0 добавляет ручную отметку ключевых сообщений.

## Что добавлено

Теперь при ручной проверке инфоповода можно выбрать сообщение во вкладке **«Вся лента»** и нажать кнопку:

```text
Ключевое
```

После этого сообщение закрепляется во вкладке **«Ключевые сообщения»** для текущего инфоповода.

## Как это работает

- вручную отмеченные сообщения показываются первыми;
- автоматический алгоритм подбирает остальные ключевые сообщения ниже;
- сообщение закрепляется только для конкретного инфоповода;
- отметка сохраняется в Supabase или локальной SQLite-базе вместе с остальными ручными правками;
- закрепленное сообщение можно удалить из ключевых кнопкой **«Убрать из ключевых»** во вкладке **«Ключевые сообщения»**.

## Что заменить в GitHub

Замените файлы:

```text
src/app.py
src/manual_db.py
README.md
```

После замены выполните:

```text
Commit → Push origin
```

Если Streamlit Cloud не обновился автоматически:

```text
Manage app → Reboot app
```
