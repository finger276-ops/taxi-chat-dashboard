# Дайджест водительских чатов — v2.8

Версия 2.8 улучшает визуал блока «Саммари периода».

## Что изменено

- Первая строка саммари больше не выводит название периода в кавычках.
- Формат первой строки теперь такой:

```text
За период 03.04.2026 — 09.04.2026 собрано ...
```

- Начальные смысловые метки выделены жирным:
  - **Негатив:**
  - **Наиболее активные чаты:**
  - **Основные инфоповоды:**
  - **Чаще всего встречающиеся темы/теги:**
  - **Основные источники негатива:**
- Для уже сохраненных ручных саммари добавлена мягкая нормализация отображения: старый формат вида `За период «03-09 апреля» (03.04.2026 — 09.04.2026)` в визуале приводится к новому виду.

## Что заменить в GitHub

Замените файлы:

```text
src/app.py
README.md
```

После замены выполните:

```text
Commit → Push origin
```

Если Streamlit Cloud не обновился автоматически:

```text
Manage app → Reboot app
```
