# Дайджест водительских чатов — v3.2

Версия 3.2 исправляет расчет саммари и метрик при выборе нескольких периодов.

## Что исправлено

- Саммари теперь берет начало и конец периода из выбранных периодов Supabase, а не только из дат сообщений.
- При выборе нескольких периодов первая строка саммари показывает общий диапазон, например: `03.04.2026 — 16.04.2026`.
- Метрика **«Чатов»** перед таблицей инфоповодов теперь считается по уникальным чатам в сообщениях, а не по максимальному `chat_count` внутри одного инфоповода.
- Саммари и метрики перед таблицей используют один и тот же набор сообщений, поэтому значения больше не должны расходиться.
- В саммари одинаковые названия инфоповодов группируются, чтобы не было дублей вроде двух строк **«Коэффициенты, приоритет и тарифы»**.
- Если для выбранного набора периодов уже было сохранено ручное саммари, первая строка с расчетными метриками автоматически синхронизируется с текущими выбранными периодами.
