# Дайджест водительских чатов

Версия 2.2: добавлен универсальный импорт CSV/Excel из Медиалогии, Brand Analytics и других систем.

## Что поддерживает загрузчик

- CSV Медиалогии;
- Excel Медиалогии (`.xlsx`, `.xls`);
- CSV Brand Analytics с техническими строками перед шапкой;
- универсальные CSV/Excel-файлы, если в них есть дата, текст, источник/чат, автор и ссылка.

Загрузчик автоматически ищет строку с заголовками, определяет систему и приводит колонки к единому формату дашборда.

## Что заменить в GitHub

Минимально:

```text
src/app.py
src/preprocess.py
src/io_utils.py
src/import_adapters.py
src/persistent_store.py
requirements.txt
README.md
```

После замены сделайте Commit → Push origin. В Streamlit Cloud при необходимости выполните Reboot app.

## Версия 2.3 — редактирование истории загрузок

В разделе **Загрузка файла → История и редактирование загруженных файлов** можно выбрать загруженный период и изменить:

- название периода;
- дату начала и дату окончания;
- название исходного файла;
- статус периода;
- комментарий к периоду.

Статусы:

- `active` — период показывается в основном фильтре периодов;
- `hidden` — период скрыт из фильтра, но остается в истории;
- `archived` — период архивный и также не попадает в основной фильтр;
- полное удаление удаляет период и его обработанные строки из Supabase.

Функция доступна только в режиме администратора, если настроен `ADMIN_PASSWORD`.
