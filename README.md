# Дайджест водительских чатов — v2.7

Версия 2.7 исправляет выбор целевого инфоповода при ручном объединении тем.

## Что исправлено

- Выпадающий список для объединения теперь хранит выбранный инфоповод по внутреннему `event_id`, а не по текстовой подписи.
- Это устраняет проблему, когда тема визуально выбиралась, но фактически не подставлялась в действие объединения.
- Добавлен поиск по целевому инфоповоду, чтобы проще находить нужную тему в большом списке.
- Если названия тем одинаковые или похожие, выбор все равно работает корректно, потому что внутри используются уникальные идентификаторы.
- При объединении по-прежнему переносится вся видимая тема целиком: все исходные события/волны обсуждения, скрытые под выбранной строкой.

## Проверка

Вверху дашборда должна появиться подпись:

```text
Версия 2.7: исправлен выбор целевого инфоповода при объединении
```

Проверка функции:

1. Откройте карточку инфоповода.
2. Перейдите во вкладку «Правки».
3. В блоке «Объединить с другим инфоповодом» начните вводить название целевой темы в поле поиска.
4. Выберите целевой инфоповод в выпадающем списке.
5. Под списком должна появиться подпись «Выбран целевой инфоповод: ...».
6. Нажмите «Объединить».
