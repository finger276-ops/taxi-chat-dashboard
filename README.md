# taxi_chat_dashboard v20

Патч исправляет ошибку в блоке сравнения периодов:

`TypeError` при сортировке периодов в `build_period_comparison_df`.

Причина: в Supabase даты разных периодов могут приходить в смешанном формате: timezone-aware, timezone-naive, пустые значения или строки. Pandas может падать при сортировке таких значений.

Что изменено:
- сортировка периодов переведена на стабильный строковый ключ `YYYY-MM-DD HH:MM:SS`;
- `period_name` принудительно нормализуется в строку;
- блок динамики сообщений и негатива больше не должен падать при выборе нескольких периодов.

- `README.md` — необязательно.
