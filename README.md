# Дайджест водительских чатов

Версия 3.7: в выгрузку дайджеста добавлены ссылки на цитаты.

## Что изменено

В разделе **«Выгрузка дайджеста»** обновлен экспорт Word/PDF:

- под каждой ключевой цитатой добавляется строка **«Ссылка на цитату»**;
- в Word ссылка добавляется как кликабельная гиперссылка **«открыть сообщение»**;
- в PDF ссылка также отображается как кликабельная ссылка, если PDF-просмотрщик поддерживает переходы;
- если у сообщения нет ссылки в исходных данных, строка ссылки не выводится.

## Файлы патча

Заменить в GitHub:

- `src/app.py`
- `README.md`

После замены сделать `Commit` и `Push origin`. Если Streamlit Cloud не обновится автоматически, выполнить `Manage app → Reboot app`.
