# Обновление алгоритма сборки инфоповодов

Добавлен слой укрупнения инфоповодов поверх текущей кластеризации.

## Что изменилось

- Первичные инфоповоды не удаляются и не пересчитываются.
- Поверх них строятся macro-events — укрупненные смысловые темы.
- В сайдбаре появился переключатель «Уровень сборки инфоповодов»:
  - «Сбалансировано — рекомендовано»: группирует волны одной темы по дням.
  - «Крупные темы — для отчета»: сильнее укрупняет повестку для дайджеста.
  - «Подробно — первичные инфоповоды»: показывает старый уровень детализации.
- В таблице инфоповодов добавлена колонка «Первичных событий».
- В карточке темы показывается, из скольких первичных событий/волн собран укрупненный инфоповод.
- Для администратора добавлен блок «Качество сборки»: сколько было первичных инфоповодов, сколько показывается после укрупнения и среднее число сообщений на тему.
- Word/PDF-дайджест автоматически использует выбранный уровень укрупнения.

## Важно

Новых зависимостей и изменений Supabase-схемы нет. Нужно заменить только `src/app.py`.
