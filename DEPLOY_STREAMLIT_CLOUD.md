# Публикация дашборда по ссылке через Streamlit Community Cloud

Этот вариант подходит, если нужно, чтобы дашборд открывался у любого человека, у кого есть ссылка.

## Важно про доступ

Если приложение сделать публичным, ссылку сможет открыть любой человек, у которого она есть. Не загружайте в публичный репозиторий приватные данные, если их нельзя показывать посторонним.

Текущая версия проекта уже содержит обработанные таблицы в `data/processed/`, поэтому для публикации не нужно загружать исходный CSV.

## 1. Создайте репозиторий на GitHub

Можно использовать публичный или приватный репозиторий. Streamlit Community Cloud умеет работать с public и private GitHub-репозиториями, но для приватных нужно выдать Streamlit доступ к private repos.

## 2. Загрузите проект в репозиторий

В репозитории должны быть файлы:

```text
streamlit_app.py
requirements.txt
src/
data/processed/
.streamlit/config.toml
```

Главный файл для запуска: `streamlit_app.py`.

## 3. Откройте Streamlit Community Cloud

1. Зайдите на `share.streamlit.io`.
2. Войдите через GitHub.
3. Нажмите **Create app** / **New app**.
4. Выберите GitHub-репозиторий.
5. Выберите ветку, обычно `main`.
6. В поле **Main file path** укажите:

```text
streamlit_app.py
```

7. Нажмите **Deploy**.

После сборки появится ссылка вида:

```text
https://your-app-name.streamlit.app
```

Ее можно отправлять другим людям.

## 4. Сделайте приложение публичным

В настройках приложения откройте раздел **Sharing** и выберите публичный режим просмотра. После этого любой человек со ссылкой сможет открыть дашборд.

## 5. Ограничение ручных правок

В локальной версии ручные правки сохраняются в `data/manual_actions.sqlite`.

На Streamlit Community Cloud это файл внутри временного окружения. Он может сбрасываться при перезапуске, redeploy или обновлении приложения. Для постоянного хранения ручных правок лучше подключить внешнюю БД:

- Supabase Postgres;
- Neon Postgres;
- обычный VPS + SQLite/Postgres;
- Google Sheets как простое хранилище правок.

Для быстрого просмотра по ссылке текущего варианта достаточно. Для боевого режима с сохранением модерации лучше использовать внешнюю БД.

## 6. Если нужно обновить данные

Локально установите расширенные зависимости:

```bash
pip install -r requirements-preprocess.txt
```

Затем пересоберите таблицы:

```bash
python src/preprocess.py --input data/chats.csv --output data/processed --window-minutes 60 --cluster-method tfidf --similarity-threshold 0.25 --event-gap-hours 1
```

Затем закоммитьте обновленные файлы из `data/processed/` в GitHub. Streamlit Cloud автоматически перезапустит приложение после `git push`.
