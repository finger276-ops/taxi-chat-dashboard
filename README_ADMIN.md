# Режим администратора

Версия 1.5 добавляет простой admin-режим для публичного дашборда.

## Что видит обычный пользователь

Без пароля доступны только:

- просмотр инфоповодов;
- фильтры;
- поиск по сообщениям;
- просмотр карточки инфоповода;
- просмотр ключевых сообщений и всей ленты.

Недоступны:

- загрузка нового CSV;
- создание инфоповода;
- ручная правка описаний;
- объединение тем;
- перенос сообщений;
- отметка «Нерелевант»;
- скрытие сообщений и тем.

## Как настроить пароль

В Streamlit Cloud откройте:

```text
Manage app → Settings → Secrets
```

Добавьте:

```toml
ADMIN_PASSWORD = "ваш_пароль"
```

Также должны остаться ваши Supabase-секреты:

```toml
SUPABASE_URL = "https://xxxxxxxx.supabase.co"
SUPABASE_SERVICE_ROLE_KEY = "..."
SUPABASE_STORAGE_BUCKET = "dashboard-csv"
```

После сохранения секретов перезапустите приложение:

```text
Manage app → Reboot app
```

## Как войти

В левой панели появится блок **«Вход администратора»**. Введите пароль и нажмите **«Войти»**.

После входа появятся:

- раздел **«Загрузка CSV»**;
- блок **«Создать инфоповод»**;
- вкладка **«Правки»** в карточке инфоповода;
- действия с отдельными сообщениями.

## Если пароль не задан

Если `ADMIN_PASSWORD` не задан, приложение покажет предупреждение и оставит режим правок открытым. Это удобно для локального теста, но небезопасно для публичной ссылки.
