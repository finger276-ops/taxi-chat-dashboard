# Bulk message actions

Добавлена возможность выбирать несколько сообщений во вкладке «Вся лента» карточки инфоповода и применять к ним массовые действия:

- пометить выбранные сообщения как нерелевантные для текущего инфоповода;
- перенести выбранные сообщения в другой инфоповод;
- удалить из ленты / скрыть во всех разделах дашборда.

Удаление реализовано через существующий механизм `hide_message(..., hidden=True)`, чтобы не удалять исходные данные физически и сохранить возможность аудита ручных действий.

Точечные действия с одним сообщением сохранены: при выборе одной или нескольких строк ниже массового блока показывается карточка первого выбранного сообщения.
