# Постоянное хранение периодов в Supabase

Эта версия добавляет постоянное хранение данных вне Streamlit Cloud.

## Что хранится в Supabase

- список загруженных периодов;
- обработанные таблицы `messages`, `events`, `discussions`, `discussion_messages`, `event_discussions`;
- ручные правки: переименование, описание, объединение, перенос сообщений, «нерелевант», ручные инфоповоды;
- опционально — исходные CSV в Supabase Storage.

## 1. Создай проект Supabase

Создай проект на Supabase и открой SQL Editor.

## 2. Выполни SQL

Скопируй и выполни файл:

```text
sql/supabase_schema.sql
```

## 3. Добавь секреты в Streamlit Cloud

В Streamlit Cloud открой приложение:

```text
Manage app → Settings → Secrets
```

Добавь:

```toml
SUPABASE_URL = "https://xxxxxxxx.supabase.co"
SUPABASE_SERVICE_ROLE_KEY = "твой_service_role_key"
SUPABASE_STORAGE_BUCKET = "dashboard-csv"
```

`SUPABASE_STORAGE_BUCKET` необязателен. Если bucket не создан, обработанные данные все равно сохранятся в Postgres, а дашборд продолжит работать.

## 4. Не коммить secrets.toml

Локально можно создать `.streamlit/secrets.toml`, но этот файл нельзя загружать в GitHub.

## 5. Как теперь работать

1. Открой дашборд.
2. Перейди в «Загрузка CSV».
3. Укажи название периода, например `24.04.2026–30.04.2026`.
4. Загрузи CSV.
5. Нажми «Загрузить и пересобрать».
6. Период появится в фильтре «Периоды».

Можно выбирать один или несколько периодов. Ручные правки теперь сохраняются в Supabase и не пропадают после redeploy.

## Важное замечание про публичный доступ

Если приложение публичное, любой человек со ссылкой сможет загружать CSV и вносить правки. Следующий рекомендуемый этап — добавить admin-пароль для режима загрузки и модерации.
